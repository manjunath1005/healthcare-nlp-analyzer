# 🏥 Healthcare NLP Analyzer

An AI-powered healthcare NLP application that automatically analyzes medical reports and predicts the most relevant medical specialty using a Transformer-inspired deep learning architecture with Self-Attention and Positional Encoding.

The system also provides explainable AI insights by highlighting the most influential medical terms contributing to the prediction.

---

## 🚀 Features

### 📄 Medical Report Analysis
- Upload medical reports in `.txt` format
- Paste report text directly into the application
- Automatic specialty classification

### 🧠 Explainable AI
- Attention-based interpretation
- Displays influential medical terms
- Improves prediction transparency

### 📊 Interactive Dashboard
- Modern healthcare-themed UI
- Confidence score visualization
- Top prediction probabilities
- Interactive importance charts

### 📑 PDF Report Generation
- Download prediction results
- Export influential medical terms
- Share analysis reports easily

## 🏗️ Project Architecture

Input Medical Report
↓
Tokenizer
↓
Embedding Layer
↓
Positional Encoding
↓
Multi-Head Self Attention
↓
Classification Layer
↓
Medical Specialty Prediction
